Predicting Employee Attrition

When people leave an organization, reactive hiring is expensive and disruptive. This project builds a two-part machine learning pipeline to flag at-risk employees before they walk out the door — using ensemble models, recall-focused tuning, and a Power BI dashboard to make predictions actionable.

Python · scikit-learn · pandas Random Forest · AdaBoost GridSearchCV · 5-fold CV Power BI Dashboard DAT 430 · SNHU
Power BI — Model Comparison & Risk Indicators
RF vs AdaBoost correct predictions side-by-side — interactive filters let stakeholders slice by job satisfaction, tenure, and years of experience
STEP 01
Baseline Model

Logistic regression using income and manager tenure. Achieved ~70% accuracy but weak recall — proving simple features weren't enough and setting a benchmark to beat.

STEP 02
Feature Engineering

Added high_income and tenured binary flags, plus one-hot encoding for job role, department, and marital status.

STEP 03
Ensemble + Tuning

Random Forest and AdaBoost tuned with GridSearchCV optimizing for recall — because missing an at-risk employee costs more than a false alarm.

~87%
